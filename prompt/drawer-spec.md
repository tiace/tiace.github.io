# ドロワーメニュー 画面仕様書

## 概要

全スクリーンに常駐するドロワーボタンを配置し、タップ/クリックでサイドドロワーを開く。
現在スクリーンベースのナビゲーション（各画面内のボタン）を補完し、
どのスクリーンからでも他の機能へ即座に移動できるようにする。

---

## 設計方針

### なぜドロワーか

現状の課題:
- focus 画面からは「Finished」以外へ移動できない（To-doを確認したくても戻れない）
- history / manage 画面の行き来に複数ステップかかる
- 各スクリーンにナビボタンが散在していて一貫性がない

ドロワーで解決すること:
- どのスクリーンからでもワンアクションで全機能にアクセス
- メインの作業エリアを汚さず、常に画面端に待機
- 現在の状態（実行中タスク・To-do件数）をまとめて表示

### 参考パターン（実績のあるWebアプリ）

| アプリ | パターン | 参考要素 |
|-------|---------|---------|
| Linear | 左サイドレール（アイコンのみ） | コンパクトな常駐ボタン、状態バッジ |
| Notion | 左スライドサイドバー | ホバーで展開、アイテム構造 |
| Todoist | 左ドロワー（モバイル） | セクション分け、タスク件数バッジ |
| Things 3 | サイドバー + フォーカスモード | フォーカス中は最小化 |
| Vercel Dashboard | 固定左ナビ + モバイルでハンバーガー | 現在地ハイライト |
| iOS Reminders | ボトムシート | モバイルでの操作性 |
| Superhuman | キーボード中心 + 最小UI | フォーカス中は邪魔しない |

Toprio に合わせた選択:
- **右下固定のフローティングボタン** → メインコンテンツを中央に保ちつつ干渉しない
- **右側からスライドインするドロワー** → モバイル・デスクトップ共通のパターン
- **小さく・薄く** → フォーカスアプリらしい控えめさ

## ドロワートリガーボタン

### 配置

```
┌─────────────────────────────────┐
│                                 │
│    [メインコンテンツ中央]         │
│                                 │
│                                 │
│                        [●]      │ ← fixed, bottom-right
└─────────────────────────────────┘
```

- `position: fixed`、`bottom: 1.5rem`、`right: 1.5rem`
- 全スクリーンで常に表示（z-index: 50）

### 見た目

- サイズ: 44×44px（タップターゲット最小サイズ）
- 形状: 円形（`rounded-full`）
- 色: `bg-muted` + `text-muted-foreground`（目立ちすぎない）
- アイコン: `Menu`（ハンバーガー）→ 開いているときは `X`
- ホバー: `bg-muted/80`、わずかに拡大（`scale-105`）

### バッジ（コンテキスト表示）

To-doが1件以上ある場合、ボタン右上に小さいバッジを表示:
- サイズ: 16×16px の赤丸、最大99+
- focus画面中は「実行中」を示すパルスアニメーション（`animate-pulse`の緑ドット）でも可

## ドロワーパネル

### レイアウト

```
┌──────────────────────────────────┐
│ overlay (backdrop)               │
│                    ┌─────────────┤
│                    │  [X]        │ ← 閉じるボタン
│                    │─────────────│
│                    │  Toprio     │ ← アプリ名
│                    │─────────────│
│                    │  現在のタスク │ ← フォーカス中のみ表示
│                    │─────────────│
│                    │  ナビゲーション│
│                    │  > Start    │
│                    │  > Focus    │
│                    │  > To-dos 3 │
│                    │  > History  │
│                    │─────────────│
│                    │  (将来: 設定) │
└────────────────────┴─────────────┘
```

### サイズ

- 幅: `280px`（`max-w-xs`相当）、モバイルは画面幅の `80%`
- 高さ: `100svh`（フルスクリーン）
- 右端固定（`right: 0`）

### アニメーション

- 開く: 右から左へスライドイン（`translateX(100%) → translateX(0)`、200ms ease-out）
- 閉じる: 左から右へスライドアウト（150ms ease-in）
- バックドロップ: `bg-black/30` でフェードイン
- ドロワー外クリックで閉じる

## ドロワー内コンテンツ

### ヘッダー

```
Toprio                          [X]
```

- アプリ名（`text-sm font-medium uppercase tracking-[0.3em] text-muted-foreground`）
- 閉じるボタン（`X` アイコン）

### 現在のタスクセクション（focus画面中のみ表示）

```
┌─────────────────────────┐
│  ▶ Now                  │
│  [タスク名]              │
│  00:12:34               │
└─────────────────────────┘
```

- `bg-sticky rounded-xl px-4 py-3`（既存のstickyカラーを流用）
- タスク名・経過時間をリアルタイム表示
- このセクションはfocus画面以外では非表示

### ナビゲーションセクション

各アイテム:
- 高さ: 44px（タップしやすい）
- 角丸: `rounded-xl`
- 現在のスクリーンはハイライト（`bg-muted`）
- アイコン + ラベル + バッジ（必要時）

```
アイテム一覧（スクリーン対応）:

  🏠  Start         → start スクリーン
  ▶  Focus          → focus スクリーン（タスク実行中のみ表示）
  ✓  To-dos    [3]  → manage スクリーン（件数バッジ）
  🕐  History       → history スクリーン（historyOrigin を "drawer" に）
```

アイコン（lucide-react）:
- Start: `Sparkles` または `Plus`
- Focus: `Play`
- To-dos: `ListChecks`
- History: `Clock`

## 状態別のドロワー動作

| スクリーン | Focus セクション | 現在地ハイライト | 備考 |
|-----------|---------------|----------------|------|
| start     | 非表示         | Start          | |
| focus     | 表示（タスク名+経過時間） | Focus | タスクがないときは非表示 |
| finished  | 非表示         | なし           | Start/Focus の中間状態 |
| manage    | 非表示         | To-dos         | |
| history   | 非表示         | History        | |

---

## ナビゲーション遷移ルール

ドロワーのナビアイテムをタップしたとき:

1. ドロワーを閉じる
2. 対応するスクリーンへ遷移

特殊ケース:
- **Focus**タップ: `state.current` がない場合は無効化（グレーアウト）またはStartへ
- **History**タップ: `historyOrigin` は `"drawer"` とし、Backボタンは元のスクリーンに戻るように
- **現在地と同じスクリーン**タップ: ドロワーを閉じるだけ（遷移なし）

---

## アクセシビリティ

- ドロワー open 時に `role="dialog"` と `aria-modal="true"`
- `aria-label="ナビゲーションメニュー"`
- フォーカストラップ: ドロワー内のフォーカスがループする
- `Escape` キーで閉じる
- ドロワーが開いた瞬間、閉じるボタンにフォーカスを移す

## 実装コンポーネント構成

```
components/toprio/
  drawer-button.tsx   ← フローティングトリガーボタン（バッジ含む）
  app-drawer.tsx      ← ドロワーパネル本体
```

`toprio-app.tsx` の変更:
- `drawerOpen` state を追加（`useState<boolean>(false)`）
- `<DrawerButton>` と `<AppDrawer>` を全スクリーンのラッパーとして配置
- 各スクリーンへの `onNavigate` コールバックをドロワーに渡す

## スタイリング方針

既存のデザイン変数を優先:
- パネル背景: `bg-card`（既存カード色）
- ボーダー: `border-l border-border`
- 現在地ハイライト: `bg-muted`
- アクティブ文字: `text-foreground`
- 非アクティブ: `text-muted-foreground`
- ドロワーシャドウ: `shadow-xl`

新規CSS変数は不要。既存テーマ変数で対応可能。
